PROJECT WOLF – VRM

PROJECT WOLF là dự án game Ma Sói trực tuyến được phát triển với mục tiêu mang lại trải nghiệm chơi realtime trên trình duyệt, tập trung vào giao diện Dark Fantasy, gameplay trực quan và khả năng chơi cùng nhiều người.

Công nghệ sử dụng:
- Next.js
- React
- TypeScript
- Supabase
- Supabase Realtime
- Vercel

Các chức năng chính:
- Tạo và tham gia phòng chơi
- Phân vai tự động
- Chu kỳ Ngày / Đêm
- Hành động theo vai trò
- Bỏ phiếu realtime
- Đồng bộ trạng thái người chơi
- Chat trong phòng
- Theo dõi lịch sử diễn biến trận đấu
- Tổng kết và xác định phe chiến thắng

Dự án hiện đang trong quá trình phát triển và hoàn thiện.
